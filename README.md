# GameVault

```
一个使用 Java 从零手写的控制台游戏账号管理系统。

用于通过实际项目复习 Java 基础，并练习需求拆分、代码组织和独立开发能力。
```

## 题目

```
游戏账号管理系统
```

## 需求

```
第一阶段只做 Java 控制台版。 不用数据库、不用 Maven 依赖、不用 AI 生成代码，IDEA 随便用。

需求是：系统启动后显示菜单，用户可以反复操作，直到主动退出。

====== 游戏账号管理系统 ======

1. 注册账号
2. 登录账号
3. 查看所有账号
4. 修改账号
5. 删除账号
6. 退出系统
   请选择：


注册：账号 ID 不能重复；用户名不能为空；密码至少 6 位；初始等级为 1，初始金币为 0。
登录：输入账号 ID + 密码；正确显示登录成功以及账号信息；ID 不存在或密码错误都要提示。
查询：显示所有账号的 ID / 用户名 / 等级 / 金币；没有账号时不能直接打印个寂寞。
修改：根据 ID 找账号；允许修改用户名和密码；ID 不允许修改，并继续满足原来的校验规则。
删除：根据 ID 删除；不存在要提示；删除之前要求用户输入 Y/N 二次确认。
退出：退出整个程序，而不是只退出一次 switch。
加分需求：支持给指定账号增加金币；根据等级从高到低显示排行榜；实现简单的登录失败次数限制，比如连续输错 3 次结束本次登录。

查：支持id或用户名，不能展示明文密码
```
